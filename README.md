# 🤖 Yart AI Agent

An intelligent AI chatbot agent built using **n8n** low-code automation platform.

## ✨ Features
- 💬 Chat interface trigger
- 🧠 Google Gemini as AI brain
- 🔍 Real-time Google Search (SerpAPI)
- 🧮 Built-in Calculator
- 💾 Conversation Memory

## 🛠️ Tech Stack
- n8n (workflow automation)
- Google Gemini API
- SerpAPI

## 📥 How to Import
1. Download `Yart AI (1).json`
2. Open your n8n instance
3. Go to **Workflows → Import**
4. Upload the JSON file
5. Add your own API credentials
6. Activate & enjoy!
